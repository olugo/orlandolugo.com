# Publish to GitHub Pages

This bundle is ready for the root of `olugo/orlandolugo.com`.

1. Open the repository on GitHub.
2. Select **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and the `images` folder from this bundle.
4. Replace the existing `index.html` when GitHub asks.
5. Commit directly to `main`, or create a branch and pull request if you want one final review.

Do not remove the repository's `CNAME` file or any existing GitHub Pages domain settings.
